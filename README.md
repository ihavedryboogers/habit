# habit

Консольный трекер привычек. Отмечайте полезные дела, сделанные за день, и следите за стриками — прямо из терминала.

## Установка

```sh
brew tap ihavedryboogers/habit
brew install habit
```

## Использование

Запуск без аргументов открывает интерактивную таблицу «привычки × дни»:

```sh
habit
```

Сегодняшний день всегда — крайний правый столбец; заглянуть в будущее нельзя, зато в прошлое можно листать сколько угодно. Дни с даты создания привычки и до вчера, если их не отметили явно, считаются осознанно пропущенными (✗) — сегодняшний день исключение, он остаётся пустым, пока не закончился. Дни до создания привычки — просто пустые. Вместо колонки «стрик» — растущий значок за непрерывную серию (🌱 → 🔥 → 🔥🔥 → 🔥🔥🔥 → 🚀 → 🚀🚀 → 👑). Внизу по умолчанию — мотивирующая фраза; подсказки по клавишам скрыты за `h`.

- `↑` `↓` — выбрать привычку, `←` `→` — выбрать день (на краю окна листает дальше в прошлое)
- `Shift+←` `Shift+→` — прыжок на неделю
- `Home` — вернуться к сегодняшнему дню
- `Enter` — переключить отметку в ячейке: пусто → ✓ (сделано) → ✗ (осознанно пропущено) → ✓ …
- `e` — очистить ячейку (сделать пустой)
- `m` — режим перемещения: `↑` `↓` двигают саму привычку, повторное `m`/`Enter`/`Esc` — выход из режима
- `h` — показать/скрыть список горячих клавиш
- `s` — настройки (цвет, количество дней, свои мотивирующие фразы) — стрелками и Enter
- `t` / `d` — быстрые ярлыки к тем же настройкам (цвет / количество дней)
- `a` — добавить привычку, `Delete` — удалить выбранную
- `q` / `Esc` — выход

Также доступны обычные подкоманды (например, для скриптов):

```sh
habit add "Спорт"              # добавить привычку
habit done "Спорт"             # отметить выполненной сегодня
habit done "Спорт" 2026-09-14  # отметить выполненной за конкретную дату
habit fail "Спорт" 2026-09-14  # отметить осознанно пропущенной
habit undone "Спорт"           # снять отметку (сделать пустой)
habit list                     # список привычек, статус на сегодня и текущий стрик
habit remove "Спорт"           # удалить привычку
```

Данные хранятся локально в `~/.habit/data.json`.

## Сборка из исходников

Нужен [.NET SDK 10](https://dotnet.microsoft.com/download).

```sh
dotnet build
dotnet run -- list
```

Публикация автономного бинарника:

```sh
dotnet publish -c Release -r osx-arm64   # или osx-x64
```
